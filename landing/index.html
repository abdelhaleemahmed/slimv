slimv

shrink video — keep the quality

A small command-line toolkit that drives ffmpeg to re-encode your video libraries to H.265 / AV1 — analyzing what's on disk, benchmarking encoders on your own footage, and verifying every output before you delete a single source.

Python 3.9+  ·  needs ffmpeg / ffprobe on your PATH

See it in action

Four commands: inspect → benchmark → encode → verify.

slimv — a real run 
$ slimv analyze "D:\Courses\ML Foundations"
273 files · 59.53 GB · 1280x720 H.264 · ~3–5 Mbps
Recommendation: mostly H.264 — re-encoding to H.265 will cut size a lot.
  Projected output: ~24 GB  →  ~60% smaller.

$ slimv benchmark lesson1.mp4 --length 30s
  Profile    VMAF    Size(MB)   Speed×RT   HW
  qsv        91.15   1.70       1.79       yes
  qsv-hq     91.80   2.65       1.76       yes   <- chosen
  balanced   91.80   1.57       1.11       no

$ slimv encode SRC DST --profile qsv-hq --hwdec qsv --copy-audio
[273/273] ✓  59.53 GB → 8.6 GB  (≈88% smaller)

$ slimv verify SRC DST --hwaccel qsv
SAFE-TO-DELETE: 273   KEEP-SOURCE: 0
ALL VERIFIED — these sources are safe to remove.

How it works

Data-driven, and safe by default.

1

Analyze

Scan a library — codecs, bitrates, sizes — and estimate what's reclaimable.

2

Benchmark

Encode a real sample several ways and score each with VMAF. Pick on data.

3

Encode

Re-encode the tree with a quality-preserving profile, on GPU if you have one.

4

Verify

Full-decode every output and match its length before any source is removed.

What it does

One tool, ffmpeg underneath.

🧠 Benchmark on your content

VMAF-scored comparisons on real footage — the choice is data, not folklore.

⚡ Hardware acceleration

Intel Quick Sync & NVIDIA NVENC encode fast and keep the CPU free.

👁️ Trust your eyes

eyeball & downscale-test leave clips to compare where VMAF can't be trusted.

✅ Never lose a source

The verify gate proves every output is intact before you delete anything.

Quick install

A wheel from the latest release — pulls in its one dependency automatically.

pip install https://github.com/abdelhaleemahmed/slimv/releases/download/v0.2.0/slimv-0.2.0-py3-none-any.whl

Requires ffmpeg / ffprobe on your PATH. For a virtual-environment setup, the full ffmpeg feature/version table, and hardware (Intel QSV / NVIDIA NVENC) notes, see the installation guide.
