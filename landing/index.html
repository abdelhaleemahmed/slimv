slimv

shrink video — keep the quality

A small command-line toolkit that drives ffmpeg to re-encode your video libraries to H.265 / AV1 — analyzing what's on disk, benchmarking encoders on your own footage, and verifying every output before you delete a single source. Typically 40–80% smaller, with no visible quality loss.

Clone the repo github.com/abdelhaleemahmed/slimv Download release latest .whl / .tar.gz Read the docs install & usage guide

Quick install

pip install https://github.com/abdelhaleemahmed/slimv/releases/download/v0.2.0/slimv-0.2.0-py3-none-any.whl

Requires ffmpeg / ffprobe on your PATH. For a virtual-environment setup, the full ffmpeg feature/version table, and hardware (Intel QSV / NVIDIA NVENC) notes, see the installation guide.

What it does

🧠 Benchmark

Encodes a real sample several ways and scores each with VMAF — data, not guesswork.

⚡ Hardware

Intel Quick Sync & NVIDIA NVENC to encode fast and keep the CPU free.

👁️ Eyeball

eyeball & downscale-test leave clips to compare where VMAF can't be trusted.

✅ Verify

Full-decode check that every output is intact before any source is removed.
